# The Ploopy A+ Trackball

![The Ploopy A+ Trackball](https://cdn.ploopy.co/aplus-media-assets/site-photos/_MG_1872.jpg)

By some stroke of luck, you've made your way here. The Ploopy A+ Trackball. Your life will never be the same.

This repository contains all of the design and production files necessary to make a Ploopy A+ Trackball. We've also included some kick-ass documentation on how to get it made, assemble it, and program it [which you can find here](https://ploopyco.github.io/aplus-trackball/).

What are you waiting for? Your new life awaits.

## QMK?!

A+ Trackballs bought from the [Ploopy store](https://ploopy.co/product-category/trackball/aplus/) come with QMK preloaded. [Check out the documentation](https://ploopyco.github.io/aplus-trackball/) for instructions on how to load new firmware onto your device. (It's super easy!)

The firmware file that ships with all A+ Trackballs is included in this repository as well, as `firmwares/aplus.uf2`.

In case you are new to the world of QMK, it is an open-source firmware for computer input peripherals. You can find the source code for all of our firmwares in [QMK's Github repository](https://github.com/ploopyco/qmk_firmware/tree/master/keyboards/ploopyco).

Note that you may have to look for specific development branches in order to find the source for all of our firmwares, as we frequently have pending pull requests.

## Under what license is this released?

As per QMK's licensing requirements, the firmware for the Ploopy A+ Trackball is released under GPLv3. Hardware design files, including electronics and mechanical files, are released under OHL CERN v2-S. Check the respective directories for full license text.
